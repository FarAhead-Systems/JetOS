# One of the most advanced Scratch operating systems
JetOS is an operating system powered by Scratch. It is not bootable, so don't even try it.
JetOS is made by FarAhead Systems, a member of the Scratch Computing Alliance
# Notice 1
All JetOS versions not labeled under "Scratch Versions" do NOT work in Scratch. 
They may boot, but it will be broken. 
# Notice 2
JetOS uses fonts exclusive to Windows. I can't assure that it will look as 
intended on non-Windows machines.
# Notice 3
JetOS was designed on a 1920x1080 laptop at 150% Windows scale. You may
want to change your settings to that if JetOS doesn't look right
